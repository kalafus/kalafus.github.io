When scam posts hit

Remove/report accounts (Group, Community) → Save evidence → Delete scam posts → Check permissions → Reset the join link → Share selectively → Update the validated blocklist → Review pending join requests.

If posts arrive faster than admins can remove them: Temporarily set Send messages → Only admins. Restore All members when the disruption has passed.

Reset the link; maintain access

After scam posts or credible reports of scam accounts, use Group info → Share (or Invite via link) → Reset link. Reset the community link too if it may provide access. Update legitimate meeting materials. Share the new link in meetings, friend chats, or DMs, not public group chats. Keep an easy way for newcomers to obtain it.

Read more about join links

Keep a validated blocklist

Use a shared, nonpublic document that authorized people can consult and maintain. Identify reliable contacts for reports and updates. Record numbers in international format; sort by country code, then numerically.

Validate before listing. A financial request alone isn't proof of a scam; a single well-documented incident may be enough. Check join requests against the list.

Read more about the validated blocklist

Coordinate

Use a private admin/trusted-servant chat to share relevant screenshots, phone numbers, and actions taken.

Optional privacy controls: Advanced Chat Privacy / Restricted Chat → On; Send message history → Only admins. These reduce exposure.

For explanations, limitations, and documentation, see the comprehensive guide. Menu names may vary by device and WhatsApp version.
